# Security Policy — Masked Wrestlers

## Reporting a vulnerability
If you believe you found a security issue, **do not** open a public GitHub Issue.

Please email: **security@YOUR-DOMAIN.com** (replace with your address)
- Subject: `Masked Wrestlers Security Report`
- Include: steps to reproduce, affected files/paths, potential impact, and any proof-of-concept.

We will acknowledge within **72 hours** and provide an initial triage response.

## Scope
In scope:
- Website / docs portal (static HTML/JS)
- Markdown content rendering
- Catalog data (`data/catalog*.json`, `data/catalog*.csv`)
- Smart contract specs and contract code (when added)
- Backend / match receipts / signature systems (when added)

Out of scope:
- Third-party services outside our control (unless directly caused by our configuration)

## Disclosure
We prefer coordinated disclosure. Please allow time for us to patch before public discussion.
